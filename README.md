# MDCAT Prep - Pakistan's Premier Medical College Admission Test Preparation Platform

A modern, responsive education website designed specifically for MDCAT (Medical College Admission Test) preparation in Pakistan. The platform provides comprehensive study materials including MCQs, flashcards, and mnemonics for Biology, Chemistry, Physics, English, and Logical Reasoning.

## 🌟 Features

### Core Functionality
- **Interactive MCQ Practice**: Topic-wise multiple choice questions with immediate feedback
- **Smart Flashcards**: Interactive flashcard system with flip animations and progress tracking
- **Memory Mnemonics**: Easy-to-remember techniques for complex concepts
- **Dark/Light Mode**: Eye-friendly themes for day and night studying
- **Mobile-First Design**: Fully responsive design optimized for all devices

### Premium Features (PKR 200/month)
- **5,000+ Exclusive MCQs**: Additional premium questions with detailed explanations
- **Advanced Flashcards**: Enhanced flashcards with visual aids
- **Performance Analytics**: Detailed progress tracking and weak area identification
- **Ad-Free Experience**: Uninterrupted studying without advertisements
- **Priority Support**: Fast customer service response

### Study Tools
- **Progress Tracking**: Save scores and track improvement over time
- **MDCAT Countdown Timer**: Real-time countdown to exam date
- **Subject-wise Organization**: Content organized by Biology, Chemistry, Physics, English, and Logical Reasoning
- **Difficulty Levels**: Questions categorized by Easy, Medium, and Hard difficulty
- **Search & Filter**: Quick access to specific topics and concepts

## 🚀 Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with CSS Variables for theming
- **Fonts**: Inter font family from Google Fonts
- **Icons**: Font Awesome 6.0
- **Storage**: Local Storage for user data and preferences
- **Responsive Design**: CSS Grid and Flexbox
- **Animations**: CSS3 transitions and transforms

## 🛠️ Installation & Setup

1. **Clone or Download**
   ```bash
   git clone <repository-url>
   cd mdcat-prep
   ```

2. **Open Locally**
   - Open `index.html` in any modern web browser
   - No server setup required for basic functionality

3. **For Development**
   - Use Live Server extension in VS Code
   - Or use any local web server like `python -m http.server`
